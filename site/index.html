Pipeline

From trait sheet to export, in three passes

The same pipeline whether a person is drawing or an agent is calling the tools.

01 — DEFINE

Lay out the trait sheet

Bodies, heads, weapons, palettes — each trait a small sprite with a rarity weight. Set width, height, and how many frames an idle and an attack need.

02 — GENERATE

Recombine and animate

The engine draws combinations, keeps hit/hurt boxes consistent across frames, and flags collisions before anything ships. draw, edit_frames, set_hitboxes over MCP, or by hand in the editor.

03 — EXPORT

Ship or mint

One call renders a sprite sheet PNG plus an Aseprite-style atlas JSON — frame rects, FPS, loop flags, hit boxes — ready for Phaser, Unity, or a Metaplex metadata pass.

Spec sheet

Built for fighters specifically

Not a general image generator wearing a game skin — the primitives are frames, hit boxes, and animation state.

TRAITS

Rarity-weighted recombination

Dedupe, exclusions, and weighted draws so a collection doesn't repeat itself.

COMBAT

Hurt and hit boxes per frame

Boxes travel with the animation, not bolted on after the art is done.

AGENTS

13 MCP tools

create, draw, set_frame, edit_animation, export_sheet and more — any MCP client can run the pipeline unattended.

EXPORT

Engine-ready atlases

Aseprite-style JSON + PNG sheet. Reads straight into Phaser, Godot, or Unity's sprite importer.

EDITOR

Pixel editor included

Pencil, fill, mirror-X, onion skin, timeline — for the frames worth a human pass.

FORMAT

Open JSON, not a lock-in

Every sprite is plain text rows over a palette. Readable, diffable, yours.

MINT

Mint-pipeline compatible

Export maps cleanly to Metaplex-style metadata — minting itself stays a separate, audited step.

SCALE

Batches, not one-offs

Generate a hundred variants from one trait sheet in the time it takes to hand-draw three.
